# Yousef Abokamar — Portfolio Source

نسخة السورس الكاملة لأحدث تعديلات الموقع — 13 أكتوبر 2026.

## الملفات
- index.html: النصوص، الأقسام، روابط التواصل وترتيب الصفحة.
- style.css: التصميم، الألوان، الفونتات، المقاسات ونسخة الموبايل.
- app.js: الأنيميشن، البحث، الفلاتر، قائمة التواصل وتشغيل الفيديوهات.
- projects.json: بيانات الأعمال وتصنيفاتها وروابط ملفات الفيديو.
- assets/: الصور، اللوجو، الفونتات، السي في وكل الـ20 فيديو المستخدمين في الموقع.

## التشغيل على الكمبيوتر
فك ضغط الملف. افتح المجلد في VS Code وشغّله باستخدام Live Server.
أو، إذا كان Python مثبتًا، افتح Terminal داخل المجلد واكتب:

    python -m http.server 8080

ثم افتح http://localhost:8080 في المتصفح.
لا تفتح index.html مباشرة بطريقة file://؛ تحميل projects.json يحتاج HTTP.

## التعديل
غيّر الكلام في index.html، والألوان والتنسيق في style.css.
عدّل المشاريع في projects.json مع الاحتفاظ بصحة تنسيق JSON.
ضع الفيديوهات والصور الجديدة داخل assets وعدّل المسارات في projects.json.
بعد التعديل، ارفع نسخة جديدة على استضافتك كي تظهر التغييرات.

## الاستضافة
الملفات HTML/CSS/JavaScript عادية؛ لا تحتاج عملية build.
index.html موجود في جذر الملف المضغوط. توجد إعدادات vercel.json للموقع الثابت.
كل الفيديوهات موجودة داخل الملف، ولا يعتمد تشغيلها على استضافة الموقع السابقة.
روابط Google Drive الموجودة هي روابط احتياطية اختيارية.
